# Build and development

Engine pinned by the existing Partout submodule: ae65d63961652fe8fb3823e536a6fc80ce5f9c8a.
No sudo is needed. Install official tarballs under ~/.local after comparing SHA256 with
https://ziglang.org/download/index.json and https://go.dev/dl/?mode=json.

Installed Zig 0.16.0 (`zig-x86_64-linux-0.16.0.tar.xz`) and Go 1.27.1
(`go1.27.1.linux-amd64.tar.gz`, SHA256 63d339f0da5ab53635a56f2490a7984dfe12dfcff22ad749f63edaf590168445).

```sh
git submodule update --init --recursive
export PATH="$HOME/.local/zig-x86_64-linux-0.16.0:$HOME/.local/go/bin:$PATH"
~/heavy.sh bash partout/scripts/build.sh -gen -config Release -crypto openssl -wireguard -prebuilts 0.8.2
```

CMake 4.2.3 and ninja 1.13.2 are installed on this host. The initial command without
`-prebuilts 0.8.2` failed because OpenSSL development headers are absent. The supported
prebuilt fallback avoids modifying system packages. CMake downloads dependencies;
bundle `libpartout.so`, `libwg-go.so` and the selected OpenSSL shared libraries together.
The engine build outputs are ignored by the submodule and must not be committed.

Skeleton created with:

```sh
~/heavy.sh dartvel create app-dartvel --project-name passepartout --ssr
```

The installed CLI resolves to ~/dartvel_dev and generates local path dependencies.
All six platforms are enabled. Native folders are generated by Dartvel at build time.

Linux engine build passed. Run generated bindings and import tests:

```sh
cd app-dartvel
~/heavy.sh flutter pub get
~/heavy.sh dart run ffigen --config ffigen.yaml
export LD_LIBRARY_PATH="$PWD/../partout/bin/linux-x86_64/partout/lib:$PWD/../partout/bin/linux-x86_64/openssl/lib"
~/heavy.sh flutter test test/engine_test.dart
```

The Linux ABI returns malloc-owned strings; the wrapper frees every returned string and
UTF-8 input. Daemon callbacks are generated but not attached until a privileged helper
exists. Default initialization does not log private data. The enum-width warning from
ffigen is relevant to daemon options; connection remains disabled pending target ABI checks.

The root `scripts/openapi.yaml` defines the app configuration. Engine Profile and module
schemas actually live in **`partout/scripts/openapi.yaml`**. `domain/profile.dart` follows
that schema's exact field/discriminator names. Unedited OpenVPN/WireGuard/IP/on-demand
payloads remain lossless JSON; typed DNS/proxy values use the same wire representation.

Local server persistence: set `DATABASE_URL=sqlite://storage/passepartout.db` (see framework
connection-string syntax). Use only locally; authentication/multi-user isolation is not
part of this phase and VPN configuration contains credentials.

## Linux privileged helper (phase 2)

Do not run the UI or server as root. A narrowly scoped helper needs CAP_NET_ADMIN to
create/configure /dev/net/tun, addresses, routes and DNS, and restore them on disconnect,
crash or sleep. It must authenticate the local caller, validate the profile, bind the tun
controller/events to `partout_daemon_start`, keep credentials private, and serialize
start/hold/stop. The app service currently rejects connect with an explicit error. No
real VPN connection was attempted on this host.
