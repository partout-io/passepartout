# Build and development

Engine pinned by the existing Partout submodule: ae65d63961652fe8fb3823e536a6fc80ce5f9c8a.
No sudo is needed. Install official tarballs under ~/.local after comparing SHA256 with
https://ziglang.org/download/index.json and https://go.dev/dl/?mode=json.

Installed Zig 0.16.0 (`zig-x86_64-linux-0.16.0.tar.xz`) and Go 1.27.1
(`go1.27.1.linux-amd64.tar.gz`, SHA256 63d339f0da5ab53635a56f2490a7984dfe12dfcff22ad749f63edaf590168445).

```sh
git submodule update --init --recursive
export PATH="$HOME/.local/zig-x86_64-linux-0.16.0:$HOME/.local/go/bin:$PATH"
~/heavy.sh bash partout/scripts/build.sh -gen -config Release -crypto openssl -wireguard -prebuilts 0.8.2
```

CMake 4.2.3 and ninja 1.13.2 are installed on this host. The initial command without
`-prebuilts 0.8.2` failed because OpenSSL development headers are absent. The supported
prebuilt fallback avoids modifying system packages. CMake downloads dependencies;
bundle `libpartout.so`, `libwg-go.so` and the selected OpenSSL shared libraries together.
The engine build outputs are ignored by the submodule and must not be committed.

Skeleton created with:

```sh
~/heavy.sh dartvel create app-dartvel --project-name passepartout --ssr
```

The installed CLI resolves to ~/dartvel_dev and generates local path dependencies.
All six platforms are enabled. Native folders are generated by Dartvel at build time.
