# Model generation

Run `scripts/gen-models.sh [all|swift|kotlin|cpp]` from any directory. It generates
both Partout's models and the selected application models using Partout's Zig
reader and renderers. The default is `all`. Use the same Zig toolchain as Partout.
Java, npm, OpenAPI Generator, Perl, and Ruby are not required for generation.

The shared application schema is `scripts/openapi.yaml`. The wrapper passes
`ConnectionStatus,ModuleType,TaggedProfile` as external Partout types and uses
`OpenAPI` as the Swift prefix. Models retain their existing filenames, public
APIs, serialization, and formatting. Staged generation preserves the last good
output if parsing or rendering fails.

Four handwritten `Identifiable` conformances live in
`app-apple/Sources/CommonLibraryCore/Domain/Extensions/Codegen+Identifiable.swift`,
outside the generated directory. They previously lived in generated files and
would be lost on regeneration. The schema's stale `Issue.required` entry for the
nonexistent `providerLastUpdates` property was also removed during migration.
All other generated bytes remain unchanged.

Run the regression checks from the repository root:

```sh
python3 partout/tests/codegen/test_codegen.py
python3 partout/tests/codegen/test_parent_codegen.py .
```

Python is needed only for these checks. CI runs both. The application baseline is
`ci/codegen-golden.json`: 67 Swift, 67 Kotlin, and 133 C++ files. The checks compare
every filename and byte against both this manifest and checked-in models, test
repeatability and schema ordering, change a nested property to verify real schema
processing, reject unsupported input, and run with legacy tools disabled.

When intentionally changing the schema, review the generated code before updating
the affected manifest hashes. Do not update hashes to hide unexplained drift.
Old generator attribution in model headers is retained solely for byte parity;
it does not indicate a remaining dependency. See
[Partout's generator notes](../partout/tools/OPENAPI_CODEGEN.md) for supported
schema constructs and the `PARITY` cleanup backlog.
